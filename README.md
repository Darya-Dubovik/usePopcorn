# usePopcorn

Приложение для поиска фильмов, вытавления оценки и добавления в лист просмотренных с сохранением данных в local Storage.

## Демо

https://darya-dubovik.github.io/usePopcorn/

## Возможности

- Поиск фильмов
- Просмотр подробной информации о фильме
- Выставление оценки
- Добавление фильмов в список просмотренных
- Сохранение данных в Local Storage

## Технологии

- React
- TypeScript
- Vite
- CSS
